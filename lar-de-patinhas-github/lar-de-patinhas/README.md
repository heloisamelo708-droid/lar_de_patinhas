# 🐾 Lar de Patinhas

Landing page responsiva de demonstração para um projeto de adoção responsável de gatinhos.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Como visualizar
1. Baixe ou clone este repositório.
2. Abra a pasta no VS Code.
3. Abra o arquivo `index.html` no navegador (ou use a extensão Live Server).

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os arquivos `index.html`, `style.css`, `script.js` e `README.md`.
3. Entre em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.

## Personalização antes de publicar
- Troque os nomes, descrições e fotos ilustrativas pelos dados reais dos animais.
- Atualize a identidade visual e os textos conforme a instituição/projeto.
- O formulário é apenas demonstrativo: ele não envia nem armazena dados. Para receber inscrições, conecte-o a um serviço de formulários ou backend.
- As imagens são carregadas do Unsplash e precisam de internet para aparecer.
